About This Project

This project explores the publicly available WHO COVID-19 dataset. It allows users to explore COVID-19 data by country, displaying cases and deaths both as daily figures and cumulative totals.

Key Considerations

  • Totals reflect the cumulative total up until January 2026.
  • Occasional negative values arise from data corrections.
  • Alert tooltips highlight unusual data points e.g. Bahamas data.

Data sourced from the World Health Organisation (WHO).
